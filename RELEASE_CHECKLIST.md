Pre-release validation gates for the v0.1.1 bugfix release. This is a checklist to
run **later**; items marked pending reflect what has not yet been validated.

## Product (end-to-end, requires an installed model)
- [ ] First-run wizard completes on a clean machine.
- [ ] Microphone selection and signal test behave correctly with real hardware.
- [ ] Hotkey (`Ctrl + Space`) records on hold and transcribes on release.
- [ ] Transcription produces usable text with a real model.
- [ ] Text is inserted at the cursor in representative apps (document the tested apps).
- [ ] Esc cancels an active recording and an in-flight transcription.
- [ ] Failed insertion leaves the transcript recoverable (clipboard/in-memory) with a visible error.
- [ ] App never remains stuck in Recording/Transcribing after errors.

## Privacy
- [ ] Core ASR runs locally with an installed model (verify no transcript upload when enhancement is off).
- [ ] Model download network access is disclosed and matches behavior.
- [ ] Cloud enhancement is off by default; enabling it with a remote provider sends transcript text (verify disclosure matches).
- [ ] Transcript history is off by default; enabling/disabling persists and matches behavior.
- [ ] Clear Data removes exactly settings, history, logs, and models; cannot be undone (validate in a disposable environment).
- [ ] Logs do not contain audio, full transcripts, API keys, or secrets.

## Platform
- [ ] Windows: interactive validation on a physical display; packaged install.
- [ ] Linux: validate (or explicitly scope out) X11 vs Wayland hotkey behavior and `xclip` clipboard dependency.
- [ ] macOS: confirmed unsupported and documented as such.

## Packaging
- [ ] Installer builds (`scripts/build.py` + Inno Setup) succeed in CI.
- [ ] Clean install launches correctly from a fresh environment.
- [ ] Uninstall removes the application; document what user data remains.
- [ ] Upgrade path preserves the Inno `AppId` and user settings.
- [ ] First-run model setup works from the packaged build.
- [ ] Autostart option works as described.
- [ ] Resolve the entry-point/build-system gap so the `sayit` script installs, or keep `python -m sayit` as the documented path.

## Accessibility
- [ ] Keyboard navigation through all settings and the wizard.
- [ ] Visible focus indicators.
- [ ] Accessible names on all controls, including custom-painted tray/overlay widgets.
- [ ] Screen-reader validation with a real screen reader.

## Legal / naming
- [ ] Project license unchanged and present.
- [ ] Dependency licenses reviewed (see `THIRD_PARTY_LICENSES.md`).
- [ ] Model licensing confirmed with upstream before any bundling/redistribution (Parakeet CC-BY-4.0 attribution; Whisper MIT; Sherpa-ONNX conversions).
- [ ] Provisional product name **SayIt** reviewed by owner (trademark/domain/handle/package availability) before public launch.

## Documentation
- [ ] README matches shipped behavior.
- [ ] CHANGELOG updated for the release.
- [ ] Real screenshots/demo captured from the actual UI (not fabricated).
