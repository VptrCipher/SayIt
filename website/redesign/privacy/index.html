Privacy

Your voice stays yours.

See what stays on your device and when SayIt needs the network.

01 / Speech and text

Recognition runs locally.

A Sherpa-ONNX model processes your microphone audio on your device. Core dictation requires no account or API key.

Transcript enhancement is off by default. You can enable a local Ollama instance or a cloud provider. A remote provider receives transcript text only.

02 / Context and control

Choose what SayIt retains.

App context
SayIt uses process and window metadata. It does not take screenshots, scan editor content, read clipboard contents for context, or log keystrokes.
Safe zones
Mark protected apps to block recording before audio capture begins.
Vocabulary
Rules stay on your device. Create them yourself or explicitly choose Remember after a correction.
History and clearing data
Persistent transcript history is opt-in. The latest transcript stays in memory so it can be recovered if insertion fails. Clear Data removes settings, history, logs, and downloaded models.

03 / Network

When SayIt goes online.

SayIt uses the network to download speech models and when you enable a remote enhancement provider. The application contains no analytics or telemetry.
