Installation

Your first dictation.

Install the app, choose a speech model, and try your first sentence.

WindowsLinuxSourceFirst runTroubleshooting

01 / Windows

Run the installer.

You’ll need 64-bit Windows 10 or later, a microphone, and network access for the initial model download.

  1. Download the Windows installer and verify its SHA-256 checksum against the official release.
  2. Run the installer. It installs for your user under %LOCALAPPDATA%\Programs\SayIt. The desktop shortcut and launch-at-login options are off by default.
  3. Launch SayIt from the final screen or the Start Menu. Look for the tray icon and setup wizard.
Find the Windows installer →

02 / Linux

Open the AppImage.

Use a 64-bit distribution with glibc 2.28 or newer. Install xclip for text insertion. Global hotkeys may require an X11 session.

chmod +x SayIt-*.AppImage
./SayIt-*.AppImage

The setup wizard opens from the tray on first launch. Keep the AppImage wherever you want to run it from.

Find the Linux AppImage →

03 / Source

Run from source.

For development or contribution, install Python 3.12 or newer, Git, and uv.

git clone https://github.com/VptrCipher/SayIt.git
cd SayIt
uv sync
uv run python -m sayit
See the source and test instructions ↗

Set up your first dictation.

  1. Select your microphone and run the built-in input test.
  2. Download a speech model. You can finish setup without one and install it when you’re ready to dictate.
  3. Pick a hotkey. The default is Ctrl + Space.
  4. Focus an editable field. Hold the hotkey, speak, and release. Press Esc to cancel.

Troubleshooting.

Windows shows a SmartScreen warning

The installer is unsigned. Verify the file against the official GitHub release and its checksum before deciding whether to run it.

The microphone or model is unavailable

Check microphone permissions and input selection. If a model download fails, check network access and try again in the setup wizard or Settings.

The shortcut or insertion fails

Try a different shortcut, check that an editable field has focus, and check X11 and xclip on Linux. After a failed insertion, the last transcript is recoverable.

How do I uninstall?

Use Installed apps on Windows or remove the AppImage on Linux. Use Clear Data in SayIt if you also want to remove settings, history, logs, and downloaded models.
