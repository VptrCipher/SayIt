How it works

One utterance.
Four steps.

Dictation preview 01 / 04

HotkeyHold to record
Speak naturally
Transcribing on-device
Open the GitHub Actions log.Text at your cursor

  1. Hold the hotkey

    Use the configurable shortcut to start recording.

  2. Speak naturally

    Dictate prose, identifiers, URLs, or a spoken edit such as “scratch that”.

  3. Release to transcribe

    Sherpa-ONNX recognizes speech on your device. Enabled local rules format the transcript.

  4. See it at your cursor

    Text goes into the active app. Escape cancels recording or transcription. If insertion fails, the transcript stays recoverable.

Privacy

Your audio stays
on your device.

Read the privacy notes ↗

Local by default

Core dictation needs no account or API key. Context detection reads application metadata only. SayIt does not take screenshots, scrape clipboard contents, or log keystrokes.

Safe zones

Block recording before audio is captured in apps you protect.

Optional text enhancement

Off by default. If you enable a remote provider, it can receive transcript text for enhancement. Microphone audio is handled on-device.

Compatibility

Where it runs.

Installation guide ↗
Windows Primary
Windows is the primary target. Automated tests run on Windows. Packaged-install validation is in progress.
Linux Partial
The AppImage includes PortAudio and passes a packaged launch smoke test. Hotkeys may need X11 and insertion may require xclip.
macOS Unavailable
There is no public installer.

FAQ

Good questions.

Is it streaming dictation?

SayIt transcribes once, after you release the hotkey.

Does my audio leave my computer?

Core dictation runs on-device. An optional remote enhancement provider can receive transcript text if you enable it.

Does AI rewrite my words?

Core corrections are deterministic, local rules you can turn off. Optional language-model enhancement is separate and off by default.

How large are the speech models?

Roughly 100 MB to 1 GB, depending on the model you choose.

Where do downloads come from?

GitHub Releases provides the artifacts and published checksums. The download center reflects the latest published release.

Can I see the source?

Yes. SayIt is developed in the open under the MIT License. View the repository ↗
